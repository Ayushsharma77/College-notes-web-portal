# College Notes Web Portal

A web-based portal designed to store, manage, and access college notes in a centralized and organized manner.

## Objective
The objective of this project is to provide students with an easy-to-use platform where they can access subject-wise college notes anytime.

## Tech Stack
- Frontend: React.js
- Backend: Node.js with Express.js
- Database: MongoDB

## Features
- Student login system
- Upload and download notes
- Subject-wise organization of notes
- Secure access to resources
- Simple and user-friendly interface
